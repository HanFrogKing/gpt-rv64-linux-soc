# 后续方向

1. **公开复现链路**：移除原阶段构建依赖，补齐最小 initramfs、桌面包集合的构建器和可迁移 JTAG 加载工具，再在干净目录重复实际启动。
2. **TF 自主引导**：基于已完成局部验证的 R116～R118 工作继续解决全板构建、PS SD 地址路由/IRQ、匹配 XSA/FSBL、ARM loader/停机、每次启动的新 DT 和 persistent desktop。当前未纳入稳定入口。
3. **GC 性能**：先恢复压缩指令模式的前端并行性、预测和双发射，再做完整 ISA/异常/MMU/浮点/Linux 回归；公开可重复测量的 IPC、CoreMark/MHz 和真实时序。
4. **桌面体验**：降低字体/动态加载/输入处理开销，补齐持久配置；根据实际 CPU 和内存带宽再评估 2D 加速。
5. **显示改进**：VBlank、双缓冲切换与无撕裂 pageflip，保留独立连续扫描和错误计数。

这些是计划，不是已经交付的功能。没有四发射、乱序执行或完整 OpenGL 作为当前前置目标。
